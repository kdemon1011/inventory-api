## How to Reproduce

**Prerequisites** — start both servers before running any evaluation:

```bash
# Terminal 1 — Reset DB + start Inventory API (port 8000)
cd inventory && rm -f data/app.db && python main.py

# Terminal 2 — Start OpenEnv server (port 9000)
cd inventory && python -m uvicorn server.app:app --host 0.0.0.0 --port 9000
```

> Between model runs, kill both servers, reset the DB (`rm -f inventory/data/app.db`), and restart.

**Run a single model:**

```bash
# Save results + trajectory JSON (auto-generates run ID)
python run_eval.py --gym inventory --model <model_name> --save --trajectory

# Or specify a run ID to group multiple model runs together
python run_eval.py --gym inventory --model <model_name> --save --trajectory --run-id run_20260311_1830
```

> **Note**: GPT-5, GPT-5-mini, o3-mini, o4-mini, o3-pro, and GPT-5.4 require `--temperature 1.0` (reasoning models don't support temperature=0).
